RRI Project Backup

RRI Project Backup adalah utilitas lokal untuk Windows yang membantu mencadangkan folder proyek pilihan ke Google Drive milik pemilik komputer.

  • Transfer berjalan langsung dari komputer ke akun Google Drive pemilik menggunakan rclone.
  • Backup satu arah: penghapusan file lokal tidak diteruskan untuk menghapus salinan di Drive.
  • Versi lama dari file yang berubah disimpan di folder arsip backup sampai dihapus secara manual.
  • Folder dan jenis file tertentu dapat dikecualikan dari backup.

Utilitas ini tidak mengunggah file ke GitHub atau ke server yang dikelola pembuatnya. Berkas proyek hanya dikirim ke Google Drive yang dipilih oleh pemilik komputer.
