RRI Project Backup

Kebijakan Privasi

Terakhir diperbarui: 8 Oktober 2026

Data yang diakses

RRI Project Backup berjalan secara lokal di komputer pemiliknya. Berdasarkan folder dan filter yang dipilih, utilitas membaca nama, ukuran, waktu perubahan, dan isi file yang dicadangkan. Utilitas juga menggunakan token OAuth untuk mengakses file Google Drive yang dibuat atau digunakan oleh aplikasi ini.

Bagaimana data digunakan dan dikirim

File terpilih dikirim langsung dari komputer ke Google Drive milik pemilik komputer melalui Google Drive API menggunakan rclone. File hanya digunakan untuk membuat dan memperbarui cadangan pada lokasi Drive yang dikonfigurasi. Perubahan versi disimpan dalam folder arsip backup. Penghapusan file lokal tidak memerintahkan aplikasi ini untuk menghapus file Drive.

RRI Project Backup tidak mengirim isi file, daftar file, atau token OAuth ke GitHub, situs web ini, atau server yang dikelola pembuatnya. GitHub hanya meng-host halaman informasi ini.

Penyimpanan lokal

Token OAuth dan konfigurasi rclone disimpan pada komputer pemiliknya. Log operasional disimpan secara lokal di folder log aplikasi Windows. Siapa pun yang memiliki akses ke komputer atau file konfigurasi tersebut mungkin dapat mengakses informasi itu; pemilik komputer bertanggung jawab menjaga akun Windows dan file konfigurasi tetap aman.

Pembagian data

Data backup diproses oleh Google saat disimpan pada Google Drive. RRI Project Backup tidak membagikan data kepada pihak lain dan tidak menyediakan server perantara.

Retensi dan kendali pemilik

Salinan dan versi lama di Drive tetap ada sampai pemilik menghapusnya sendiri. Pemilik dapat menghentikan watcher Windows, mengubah folder atau filter backup, menghapus salinan Drive, serta mencabut akses OAuth dari pengaturan keamanan Akun Google.

Kontak

Untuk pertanyaan privasi atau permintaan terkait data, gunakan alamat dukungan yang ditampilkan pada layar persetujuan OAuth RRI Project Backup di Google.
